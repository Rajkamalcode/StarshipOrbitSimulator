# StarshipOrbitSimulator
HTML/JS BASED STARSHIP ORBIT SIMULATOR

Download the HTML file and run in any browser (best for chromium based browsers), you can also know if you see Starship orbit, it passes over several countries during orbit 2-6 so keep look out.

Conditions to see Starship:

Illumination Condition: For any low-Earth-orbit satellite to be seen by human eyes, it must be illuminated by the Sun while the observer on the ground is in darkness (such as during twilight, 1–2 hours after sunset or before sunrise). 
No Engines Firing: During orbital coast, the Raptor engines are shut down, and Starship does not carry searchlights bright enough to be seen from 275 km away.
